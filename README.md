# 중기부·바이오 데스크 브리핑

중견·중소기업(중기부) + 벤처 + 바이오 담당 기자를 위한 **필독 기사 자동 브리핑 사이트**.
국내 주요 경제지 RSS를 수집·선별해, **부장 전화·후배 확인에 대비한 "놓치면 안 되는 기사"** 를
한눈에 모아 보여줍니다. 각 제목을 누르면 원문으로 이동합니다.

- **자동 갱신**: 평일 **오전 06:00**, **오후 14:00**(금요일은 **오후 13:00**) — 모두 KST
- **내 PC가 꺼져 있어도** GitHub 클라우드(Actions)가 스케줄대로 실행 → Vercel 자동 재배포
- 단독·취재 → 중기부 정책 → 담당 기업/바이오 이슈 → 주요 동향 순으로 우선 노출

---

## 무엇이 어떻게 도는가 (아키텍처)

```
[GitHub Actions cron]  ──(평일 06:00·14:00 / 금 13:00 KST)──▶  python scripts/build.py
        │                                                          │
        │  전 매체 RSS 실시간 수집·스코어링·index.html 재생성       ▼
        │                                                     index.html 커밋·푸시
        ▼                                                          │
  깃허브 서버에서 실행                                              ▼
  (내 컴퓨터 전원과 무관)                                   [Vercel] git 연동 자동 배포 ─▶ 공개 URL
```

- **엔진**: `scripts/build.py` — 파이썬 **표준 라이브러리만** 사용(설치 의존성 0). RSS 수집 →
  중복 제거 → 키워드·최신성·매체 가중치 스코어링 → 단독·취재 감지 → 섹션 분류 → `index.html` 생성.
- **스케줄러**: `.github/workflows/briefing.yml` — GitHub Actions cron. 깃허브 서버에서 도므로
  **내 노트북/PC가 꺼져 있어도** 정해진 시각에 계속 작동합니다.
- **호스팅**: Vercel. 저장소에 커밋이 올라올 때마다 자동 배포.
- **스타일**: `style.css` (초기 페이지와 자동 생성 페이지가 공유).

## 배포 방법 — 딱 두 단계 (최초 1회, 각 5분)

> 코드·자동화는 이미 100% 준비돼 있습니다. **내 GitHub·Vercel 계정 로그인만** 하면 끝입니다.
> (보안상 계정 로그인은 대신 해드릴 수 없어 이 부분만 직접 하시면 됩니다.)

### 1단계 — GitHub에 올리기

1. 깃허브에서 새 저장소 생성: <https://github.com/new>
   - 이름 예: `sme-bio-briefing` · **Public** 권장(무료 Actions 넉넉) · README 등 체크 없이 빈 저장소로 생성
2. 이 폴더에서 아래를 복붙 실행 (`<사용자명>`만 본인 것으로 교체):

```bash
git remote add origin https://github.com/<사용자명>/sme-bio-briefing.git
git branch -M main
git push -u origin main
```

3. 깃허브 저장소 → **Settings → Actions → General → Workflow permissions** →
   **"Read and write permissions"** 선택 후 저장. (자동 커밋을 위해 필요)
4. **Actions** 탭 → "브리핑 자동 갱신" → **Run workflow** 로 한 번 수동 실행해 정상 동작 확인.

### 2단계 — Vercel에 연결하기

1. <https://vercel.com/new> 접속 → GitHub 계정으로 로그인
2. **Import Git Repository** 에서 방금 만든 `sme-bio-briefing` 저장소 선택
3. 설정 그대로 두고(프레임워크 자동감지 = Other, 빌드 없음) **Deploy** 클릭
4. 배포 완료 후 나오는 `https://<프로젝트>.vercel.app` 이 **내 브리핑 사이트 주소**입니다. 북마크!

이후부터는 손댈 것 없이, 평일 06:00·14:00(금 13:00)마다 자동으로 최신화됩니다.
(GitHub Actions가 커밋 → Vercel이 자동 재배포)

## 커스터마이징

### 수집 매체 추가/변경
`scripts/build.py` 상단 `SOURCES` 리스트에 `{outlet, kind, weight, url}` 항목을 추가하세요.
`weight` 는 해당 피드 기사에 붙는 기본 가중치(담당 분야 피드일수록 높게).

### 스코어링 키워드 조정
같은 파일의 다음 리스트를 편집:
- `SCOOP_STRONG` / `SCOOP_SOFT` — 단독·취재 신호(최상단 노출)
- `KW_SME` — 중기부·중견·중소·벤처
- `KW_BIO` — 바이오·제약·헬스케어
- `KW_POLICY` — 정부·정책 일반
- `KW_EVENT` — 인수·상장·수사 등 "무슨 일 났나" 시그널

### 필독 개수·기간
`main()` 안의 `must_read = fresh[:18]`(개수), `48`(시간 창) 값을 조정.


## 수집 매체

- **중소기업뉴스**(중기중앙회 기관지) — 중기부·중소기업 정책 핵심
- **벤처스퀘어** — 스타트업·벤처 투자/현장
- **히트뉴스** — 제약·바이오 산업 전문지
- **청년의사** — 의료·바이오
- **전자신문**(중기·벤처/바이오/정책/경제/유통)
- **한국경제**(경제/바이오·IT/금융/정치)
- **서울경제**(기업/경제/산업)
- **이투데이**(산업/경제)
- **매일경제**(경제/기업) — best-effort

> 일부 매체는 데이터센터(GitHub Actions) 요청을 차단할 수 있어, 그날그날 실제로 수집된 매체만
> 하단 "수집 매체"에 표시됩니다. 수집기는 gzip 해제·다중 User-Agent 재시도·정규식 폴백으로
> 최대한 많은 매체를 살립니다.

> RSS 콘텐츠 저작권은 각 매체에 있으며, 본 도구는 **개인 열람 목적의 비상업적 큐레이션**입니다.
> 일부 매체 RSS는 비상업적·개인 사용으로 이용이 제한됩니다. 외부 공개/상업적 재배포는 피하세요.
